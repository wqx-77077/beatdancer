# Third-party credits

BeatDancer is original code. No source files from other repositories were
copied into `beatdancer/`, `rdk/` or `web/`. Where a design idea, a protocol or
a naming convention comes from another project, it is listed here and marked in
the code with a comment.

## Referenced / re-implemented

| Project | Version studied | License | What we took | Where |
|---|---|---|---|---|
| [CPJKU/beat_this](https://github.com/CPJKU/beat_this) | v1.1 | MIT | Beat-tracking pipeline shape: spectral-flux onset, dynamic-programming tempo path, then a pulse-train refinement to pull the grid onto transients. We use classical DSP instead of their transformer so it runs on the RDK CPU. | `beatdancer/audio.py` (`_beat_dp`, `align_grid`) |
| [librosa/librosa](https://github.com/librosa/librosa) | 0.10 | ISC | Mel filterbank layout, onset-strength definition (`log-mel diff, half-wave rectified, summed over bands`). Rewritten from scratch so the package has no librosa dependency. | `beatdancer/audio.py` (`mel_filterbank`, `onset_envelope`) |
| D. Ellis, *Beat Tracking by Dynamic Programming* (2007) | — | paper | The cumulative-score / backlink recursion used for beat tracking. | `beatdancer/audio.py` (`_beat_dp`) |
| [huggingface/lerobot](https://github.com/huggingface/lerobot) | 0.3 | Apache-2.0 | Feetech STS packet layout and the "one broadcast packet for the whole body" SYNC_WRITE idea, which is what makes 16 servos at 50 Hz possible. | `rdk/servo_bus.py` |
| [google-deepmind/mujoco_menagerie](https://github.com/google-deepmind/mujoco_menagerie) | main | per-model (see `unitree_g1/LICENSE`) | Unitree G1 joint naming, used by the retargeting export. The G1 XML itself is *not* vendored here. | `beatdancer/export.py` (`G1_MAP`), `sim/` |
| [D-Robotics/rdk_model_zoo](https://github.com/D-Robotics/rdk_model_zoo) | main | Apache-2.0 | The `hb_mapper` quantisation-config shape (march, calibration, input layout) used as a template for a future BPU beat model. | `rdk/hb_mapper_beatnet.json` |
| [Stanford-TML/EDGE](https://github.com/Stanford-TML/EDGE) | CVPR'23 | MIT | Conceptual reference for "music → motion" conditioning (energy-conditioned motion, beat alignment loss). Not used at runtime. | `docs/项目书.md` |

## Not used, on purpose

| Project | Why not |
|---|---|
| [madmom](https://github.com/CPJKU/madmom) | GPL-3.0; would force the whole repo to GPL |
| AIST++ / LAFAN1 datasets | non-commercial / no-derivatives terms; a hackathon repo should be redistributable |
| SMPL / SMPL-X body models | research-only licence, cannot be shipped |
| EDGE weights | PyTorch + GPU inference, does not fit a 10 TOPS board at 48 h scale |

## Audio

`assets/demo_track.wav` is generated by `tools/make_demo_track.py` from sine and
noise generators. It contains no samples, loops or recordings from third
parties, so it is safe to publish with the repo and to play on stage.
