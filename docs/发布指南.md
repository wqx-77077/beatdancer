## 还差一步：开 GitHub Pages

仓库 → `Settings` → 左侧 `Pages` → Source 选 **Deploy from a branch** → Branch 选 `main`，目录选 **/ (root)** → `Save`。

等 1～2 分钟，访问：

```
https://wqx-77077.github.io/beatdancer/dist/beatdancer.html
```

打开后点「点击开始」，能看到机器人跟着音乐跳，就说明成了。

## 常见维护

**换演示视频**：重新生成后覆盖 `dist/demo.mp4`，然后走上面三条命令。
```bash
FFMPEG_BIN="/Users/qiqi/Desktop/Deepseek HARNESS/hackathon_rdk/bin/ffmpeg" \
  python -m beatdancer.cli render assets/demo_track.wav --out dist
```

**改项目书**：编辑 `docs/项目书.md`，然后
```bash
python tools/build_docs.py            # 重新生成 docx
# 需要 PDF 的话，用 Word/WPS 导出，或让我帮你转
```

**换一首歌**：把 wav 放进 `assets/`，然后
```bash
python -m beatdancer.cli demo assets/你的歌.wav --out dist --servo-config
```
