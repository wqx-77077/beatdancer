# 上传到 GitHub 的步骤（10 分钟）

仓库已经在 `beatdancer/` 里初始化好了，代码、演示视频、网页 Demo、文档都在里面。
你只需要换成自己的账号。

## 1. 在 GitHub 上建一个空仓库

- 名字：`beatdancer`
- 可见性：**Public**（报名表要填链接，评委要能点开）
- 不要勾 "Add a README / .gitignore / license"（本地已经有）

## 2. 推到 GitHub

```bash
cd "路径/beatdancer"

# 如果还没初始化过（本仓库已 init 过，可跳过）
git init -b main

# 换成你自己的用户名和仓库名
git remote add origin https://github.com/你的用户名/beatdancer.git

git add .
git commit -m "feat: music-driven robot choreography (BeatDancer)"
git push -u origin main
```

> 大文件提示：`dist/demo.mp4` 约 1.8 MB、`dist/preview.gif` 约 3 MB，都在 GitHub 单文件
> 100 MB 限制内，直接推没问题。以后如果想放更长的视频，用 Release 的 assets，不要进仓库。

## 3. 打开 GitHub Pages（让网页 Demo 能在线点开）

仓库 → Settings → Pages → Source 选 `Deploy from a branch` → Branch 选 `main`，目录选 `/ (root)` → Save。

等 1 分钟，访问：

```
https://你的用户名.github.io/beatdancer/dist/beatdancer.html
```

这个链接可以直接填进报名表，评委点开就能听歌看机器人跳舞（手机也能开）。

## 4. 仓库信息建议

**Description**

```
Music-driven choreography for a 16-DOF servo humanoid: beat tracking → DP choreography → 50 Hz joint control. Runs on RDK X5.
```

**Topics**

```
robotics  humanoid  dance  beat-tracking  motion-planning  rdk-x5  d-robotics  embedded  numpy
```

## 5. 回填报名表的三个链接

```
https://github.com/你的用户名/beatdancer
https://github.com/你的用户名/beatdancer/blob/main/dist/demo.mp4
https://你的用户名.github.io/beatdancer/dist/beatdancer.html
```

顺便把 `README.md` 和 `docs/项目书.md` 里的 `〔你的用户名〕` 一起替换掉。

## 6. 提交前自查

```bash
cd beatdancer
python -m unittest discover tests -v     # 11 项应全过
python -m beatdancer.cli demo assets/demo_track.wav --out /tmp/check
git status --short                        # 不该出现 .DS_Store / __pycache__ / .pylibs
```

- [ ] 仓库是 Public
- [ ] `dist/demo.mp4` 能在网页里直接播放
- [ ] Pages 打开了，链接能访问
- [ ] README 里的 `〔你的用户名〕` 已替换
- [ ] 视频里没有出现别人的脸/别人的音乐
